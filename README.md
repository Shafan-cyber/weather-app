# 🌦️ Weather App

A responsive weather application built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
https://shafan-cyber.github.io/weather-app/

## ✨ Features
- Search weather by city
- Real-time temperature
- Humidity
- Wind speed
- Dynamic weather icons

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- OpenWeather API
